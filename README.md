# Book Tracker 📚

GUI-приложение на Python для управления списком прочитанных книг.

## 👤 Автор
*   **Имя Фамилия:** Лукина Света
*   **Проект:** Учебный трекер книг

## 📝 Описание программы
Приложение позволяет вести учет прочитанной литературы. Все данные сохраняются локально в файл `books.json`, что позволяет сохранять прогресс между запусками.

**Основные возможности:**
*   Добавление книг через графическую форму.
*   Валидация: проверка на заполнение всех полей и корректность числа страниц.
*   Фильтрация списка по жанру.
*   Фильтрация по объему (поиск книг длиннее N страниц).

*   **Тест 1 (Валидация):** Попробуйте нажать кнопку «Добавить книгу» с пустыми полями — вы получите предупреждение.
